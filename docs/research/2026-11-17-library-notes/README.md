Things to know before relying on them:

- They are working notes, not finished text. They give away endings (marked "[ENDING]"), and
  their dates are not all written year-month-day.
- Most pages were read through a tool that returns a small model's account of a page, not the
  page's own words. Each file says which pages were read as raw text.
- Each file ends with every page opened, every page that refused, and every item not verified.
- Nobody watched or read the works, apart from the parts of four texts the files name.
