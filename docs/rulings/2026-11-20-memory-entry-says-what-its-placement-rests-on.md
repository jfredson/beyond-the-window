# Ruling: the memory entry says what its placement rests on

Ruled by John on 2026-11-20, in conversation with the master planning session. **Decided by:
mixed** (a session proposed and recommended, John approved). Written by Claude (Fable 5.2), an
AI model.

## How it came up

The read of the live pages against John's published positions
(`docs/reviews/2026-11-20-live-pages-read-against-the-positions.md`, its first contradiction)
found that the entry on memory across conversations is set beside the list for this reason:
"The list is about what an AI model might reach for, and by the developers' own pages this
memory is kept for the user." John ruled the placement on 2026-11-18. His published position on
where current AI stands says that where a memory feature is added, a later run is built from
what earlier runs stored, and warns against arguing from who built a system or what the
builder meant by it. So the mismatch is with the stated reason, not with the placement.

## What was put to him

- *The fix:* keep the entry where he ruled it, and add one sentence to its page: "This entry is
  placed by what the developers say the memory is for. That says nothing about what stored
  memory does to how a later conversation is built." The wording was shown to him to approve
  or change.
- *Confidence:* moderate, because the session had then read only the positions record's
  summary, and said it would read the source before the sentence goes out.
- *Standard practice or judgment call:* a judgment call.
- *Strongest alternative:* leave the entry, since he ruled the placement, the list counts what
  developers offer, and a developer's own page is the only dated public record there is.

The question put to him was "Add one sentence to the memory entry saying its placement rests on
what developers say memory is for?" John: "Yes, add it". **Decided by: mixed.** He did not ask
for the wording to be changed, and the session takes the sentence as shown to be the one
approved.

## The source, read after his answer and before anything was written

The published page of his stance on current AI (Sentient Horizons, `stances/current-ai`) says:
"Where a memory feature is added, a later run is built from what earlier runs stored, which is
the nearest a model comes to the way each moment of a person is built from the ones before."
The published essay *Consciousness as Assembled Time* speaks of a memory feature that "carries
something into a later run". So the summary held.

## What is ruled

The entry stays beside the list. Its page gains the sentence above, word for word, next to the
reason for its placement.

## Not covered by this ruling

The placement itself, the same reason where it is given on the About page and in the groups
file, and any claim about what memory means for a model.
