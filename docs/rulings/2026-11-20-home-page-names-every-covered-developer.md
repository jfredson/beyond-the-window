# Ruling: the rebuilt home page names every developer the record covers

Ruled by John on 2026-11-20, in conversation with a working session (not the master planning
session). **Decided by: mixed** (a session set out three courses and gave no recommendation;
John chose one). Written by Claude (Fable 5.2), an AI model.

## How it came up

The design for the rebuild (`docs/proposals/2026-11-20-rebuild-design.md`, decision 1) asks
whether the home page names a developer. Today no developer is named off an entry page, and the
check of the built site enforces that (first-version choice 18, decided by: agent).

## What was put to him

Three courses:

- name developers on the home page;
- keep "one developer" as a link to the entry that names it;
- show a grid in which every covered developer is named, including those with nothing found,
  so that no single name stands alone.

The evidence given: all four Claude readers of the mock-ups asked for the name, and one said
leaving it out "feels coy and makes me slightly suspicious". Against naming: one company's name
at the top can read as promotion, and it would be the only name there today.

*Recommendation:* none. The session declared a conflict: every thing the records count as
offered is offered by Anthropic, which made the model doing the work.
*Standard practice or judgment call:* judgment call. The sibling sites name companies on their
home pages.

Asked "Should Beyond the Window's home page name the developers?", with the choices "Name all
covered" and "Link, no name", John answered: "Name all covered". **Decided by: mixed.**

## What is ruled

On the rebuilt home page, the developers' reading names every developer the record covers,
including each one for which nothing was found. No developer's name stands alone.

## What follows

- The check of the built site changes with the rebuild: a developer listed in
  `data/developers.toml` may be named in the developers' reading on the home page. It is still
  refused elsewhere on that page, and the rule against naming an AI model off an entry page is
  unchanged. This follows from the ruling and is not itself ruled.
- A cell that says nothing was found has to rest on a search that was made. Each covered
  developer is searched for each thing on the list, and the page shows when.

## What is not ruled

- **Which developers are covered** (decision 2 of the design). The ruling says all covered
  developers are named; it does not say who they are. The records name three today.
- **The published site.** It keeps its present rule until John approves a rebuilt page.
- **The wording of a cell,** and how "nothing found" is kept apart from "has said it will not".
