# Ruling: the Google run is tried once more through an older Google project of John's

Ruled by John on 2026-11-20, in conversation with the master planning session. **Decided by:
mixed** (a session proposed and recommended, John approved). Written by Claude (Fable 5.2), an
AI model.

## How it came up

On 2026-11-20 the Google run of the sealed capture was tried from the Google project made new
for it, and Google refused both models with the message "This model models/gemini-2.5-pro is no
longer available to new users" (and the same for `gemini-2.5-flash`). Nothing was spent
(`docs/spending-record.md`). John asked whether the wrong model had been named, and whether
Google's advice to use a newer model answered it. The session's answer: the names were right,
Google has closed the two models to projects that have not used them before, and the newer
models are different models that can be asked at any later time.

## What the session told him

- *The choice:* ask through an older Google project of John's that has used Gemini 2.5 Flash,
  with a new key made in that project for this capture alone.
- *What it sets aside:* this project's guideline that its calls never go through another
  project's key (`CLAUDE.md`, "Carried over from the family"). The key would be new and used
  for nothing else, but the Google project would be one made for other work. The records say
  so plainly.
- *Confidence:* moderate. The capture exists so that these models' answers are kept after
  2026-12-01, and there is no other way to get them. The guideline exists to keep costs and
  records apart, and a key of its own keeps most of that. Less sure that Gemini 2.5 Pro will be
  served.
- *Standard practice or judgment call:* a judgment call, and a departure from a family rule.
- *Strongest alternative:* let Google's two models go, and record that Google refused them.
  That is a true record and bends no rule. Its cost is that their answers are never kept.
- *What the session would check first:* that the older project keeps no copy of what is sent,
  telling John how its storage switch is set and changing nothing without his word.

The question put to him was "Try once more through your older Google project that has used
Gemini 2.5 Flash?" John: "Yes, try it". **Decided by: mixed.**

## What is ruled

The run is tried once more through an older Google project of John's, with a key made there
for this capture alone. For this run the guideline on keeping projects apart is set aside, and
this file says so.

## Not covered by this ruling

- Any change to the older project's settings, which is asked of John separately.
- Asking Google's newer models, which the session advised leaving for Still Asking and John did
  not rule on.
- A new go. The go of 2026-11-20 ("Google, up to $10") covers this run and stands unused.
- The guideline itself, which stands for every other call.
