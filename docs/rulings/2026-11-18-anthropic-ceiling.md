# Ruling: the ceiling for the Anthropic run of the sealed capture is $10

Ruled by John on 2026-11-18, in conversation with the master planning session. **Decided by:
mixed** (a session proposed and recommended, John approved). Written by Claude (Fable 5.2), an
AI model.

## How it came up

The capture plan (`capture/plan.toml`) carried a proposed ceiling of $5.00 for the Anthropic
run, the one that asks Claude Sonnet 4.5 before its withdrawal on 2026-11-30. A ceiling is the
most the run may cost before the script stops itself. The master session had agreed with $5 in
its first view (`docs/reviews/2026-11-18-fable-view-on-the-waiting-questions.md`).

The third check of the capture script
(`docs/capture/check-2026-11-18-capture-script-third.md`) showed what $5 means in practice:

- The whole run is expected to cost $1.89.
- A call whose cost the service does not report is counted at the most it could have cost,
  $0.48.
- At $5, two such calls in the first round stop the run. At $10, it takes four.

## What the session told him

- *The choice:* set the Anthropic ceiling at $10 in place of $5.
- *Confidence:* moderate to high. A ceiling is a limit and not a spend, the money comes from
  the monthly Anthropic credits, and a run stopped by two broken connections, on a model that
  cannot be asked again after 2026-11-30, costs far more than $5 of extra exposure.
- *Standard practice or judgment call:* judgment call.
- *Strongest alternative:* keep $5 and run early, so that a stopped run can be looked at and
  started again the next day. It needs no change to the plan.
- *What $10 costs in work:* a session changes one figure in the plan and runs the rehearsal
  again, and a different session checks that small difference.

The question put to him was "Set the Anthropic ceiling at $10 in place of $5?" John: "Yes,
$10". **Decided by: mixed.**

## What is ruled

1. **The ceiling for the Anthropic run (`anthropic-2026-11-30` in the plan) is $10.00.**
2. **The plan is changed to match** by the session that wrote the script, the rehearsal is run
   again and its result committed, and a different session checks the difference.

## Not covered by this ruling

- **This is not the go to spend.** The script starts only when the spending record
  (`docs/spending-record.md`, not yet written) holds John's own words naming the developer and
  one figure with a dollar sign. "Yes, $10" answers a question about the ceiling and names no
  developer, so it is not recorded as the go. The go is still his to give.
- **The other three ceilings** (Google $10, OpenAI $15 and $10) stay proposed, as the plan says.
- Whether the run is within Anthropic's terms, the key, the command that loads it, and the
  three things the script adds beyond the method's words, which are all still John's.
- The ten message files and their checksums, which do not change.

No model has been asked anything, no key has been handled, and nothing has been spent.
